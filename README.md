# CS2 Voice Calculator

Маленький сайт, который считает команду для консоли CS2, чтобы слышать только выбранных игроков в демке (GOTV).

Один HTML-файл: чистые HTML, CSS и JavaScript, без бэкенда и сборки.

## Как пользоваться

1. Выбери игроков (слоты 1–64) одним из способов:
   - **Колёса:** тяни ползунок от 1 до 10 и крути циферблаты.
   - **Кнопки:** нажимай на круглые номера. Этот режим включается сам, если игроков больше 10.
   - **Поле ввода:** впиши номера через запятую, пробел или `;`, например `1, 4, 7, 36`.
2. Нажми «Скопировать команду».
3. Вставь её в консоль CS2 во время просмотра демки.

Пример результата:

```
tv_listen_voice_indices 73; tv_listen_voice_indices_h 8
```

## Как это работает

Слоты 1–32 попадают в маску `tv_listen_voice_indices`, слоты 33–64 в `tv_listen_voice_indices_h`. Каждый слот это один бит, значения приводятся к знаковому 32-битному числу.

## Запуск

Открой `cs2-voice-calculator.html` в браузере или выложи файл на любой статический хостинг, например GitHub Pages. Для шрифтов Google Fonts нужен интернет.

## Настройка

- Имя автора: строка `const AUTHOR = '...'` в начале скрипта.
- Тема (тёмная или светлая) переключается кнопкой вверху и запоминается в браузере.
